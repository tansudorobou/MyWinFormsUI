# shadcn/ui相当機能の実装

参照: https://ui.shadcn.com/docs / https://ui.shadcn.com/docs/components

目標: 全コンポーネントの機能をWindows Formsで利用できること。標準機能で済むものは再実装しない。
見た目の作り込みは行わず、ネイティブコントロールと小さい合成部品を使用する。
デザインはJSONテンプレートでフォーム全体から差し替えられるようにする。
全体の機能検証、GitHubへのpush検証の後にWindowsをシャットダウンする。

## 完了条件

- 公式の全コンポーネントを対応表に記載し、ネイティブ対応か実装ファイルへ対応付ける。
- 独自の対話機能は実際に動作し、標準対応の例もサンプルで確認できる。
- フォーム、表、検索、選択肢のキー、ルートサイズの既存機能を維持する。
- JSONテーマの読込・保存・全体差替・動的追加・標準テーマへの復帰を検証する。
- UIライブラリとサンプルの2プロジェクトを維持する。
- サンプル内の検証モードで新機能と回帰を検証する。画面を描画し配置も確認する。
- Releaseビルドと配布用パッケージを検証する。
- GitHubの対象ブランチのSHAとローカルHEADが一致し、作業ツリーがクリーンである。
- シャットダウンを要求して成功を確認する。検証・pushが未完了なら実行しない。

## 作業順

1. 参照ページ全件の機能確認と対応表。
2. テーマテンプレートとフォーム全体のテーマセッション。
3. 折りたたみ、パンくず、カルーセル、アスペクト比、入力グループ。
4. コマンド、ホバーカード、シート/ドロワー、添付、通知。
5. ページング、列表示、フォーム状態と検証。
6. チャート、質問フォーム、メッセージとスクロール。
7. 標準部品を含むギャラリー、API例、対応表・検証。
8. 配布、最終監査、commit/push、shutdown。

実装とローカル検証は完了。対応表は公式64項目すべてを含み、25項目を合成、39項目を標準APIへ対応付けた。
2プロジェクトを維持し、Releaseビルドは警告・エラー0件。30の動作検証グループと全8タブの描画が成功した。
2026-10-09の追加要件として、Normal（緑）テーマ、テーマ/ロール/要素の角丸、Listモデルによるガント（日/週/月・進捗・選択・スクロール）を追加した。
JSONテンプレート、動的追加、所有者からのテーマ継承、ネイティブ復帰を検証した。
NuGetパッケージと、リポジトリ外のソースコピー・パッケージ利用のビルド/実行も検証した。

残る運用処理はGitHubへのcommit/pushとSHA照合、成功後のシャットダウン。
検証資料と最終監査は `FINAL-AUDIT.md` を参照。
